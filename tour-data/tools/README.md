# Trip-archive data pipeline & durable place-name record

Everything needed to rebuild `tour-data/trip.json` from scratch lives in this repo
(plus a few private inputs in gitignored `../data-local/` — see below). The media
GUID in every filename is the permanent key that ties names, GPS, and health data
to each photo/video forever.

## Full rebuild order (after any name/data change)

```bash
# from the repo root
python3 tour-data/tools/pipeline/apply_names_v3.py [names.json]  # 1. apply the naming-tool download
python3 tour-data/tools/pipeline/build_trip.py                   # 2. rebuild day/place structure
python3 tour-data/tools/pipeline/merge_health.py                 # 3. steps/distance + photo-altitude*
python3 tour-data/tools/pipeline/health_extend.py                # 4. elevation profiles, climbs, step curves*
python3 tour-data/tools/enrich_trip.py                           # 5. durations, walk km, stats, weather
python3 tour-data/tools/gen_sidecar.py                           # 6. refresh place-names.csv/json
# optional, when names are final:
python3 tour-data/tools/embed_places.py --write                  # 7. write names into media metadata
```

*Steps 3–4 skip gracefully (keeping trip.json's existing health data) if
`data-local/trip_health.csv` is absent.

## Refining location names — `name-tool.html`

An in-browser tool for reviewing and renaming every location. It reads the same
files the pipeline uses and exports a fresh `croatia-names-v3.json`.

```bash
# serve tour-data/ so the tool can load its data + show photo/video previews
cd tour-data && python3 -m http.server 8000
# then open:  http://localhost:8000/tools/pipeline/name-tool.html
```

Each **spot** (a GPS cluster of shots) is one card: its editable name, a preview
grid (photos, video posters, and GoPro clips), coordinates with a Google-Maps
link, a *“🔎 name on map”* link that searches your current name near those
coordinates (handy for getting the real place name right), the date/time range,
and shot counts. You can:

- rename a spot (applies to all its shots), or expand **Edit individual photos**
  to give one shot its own name (a per-photo override) or mark it deleted;
- filter by chapter, search by name/coords, sort, or show **only un-refined**
  spots (still on their raw auto-label — the gold-outlined ones);
- click any thumbnail to preview the full photo / play the video or clip.

When done, click **⭳ Download names JSON** → it saves `croatia-names-v3.json`.
Drop that file over `pipeline/croatia-names-v3.json` and run the rebuild order
above (starting at `apply_names_v3.py`). The tool seeds from the current file, so
naming is fully resumable across sessions. (`Load a JSON…` merges an older
download back in if needed.)

## What lives where

**`pipeline/` (committed — the canonical rebuild inputs):**
- `flat_items_labeled.json` — all 2,041 items with GUID, kind, GPS (incl. recovered
  GoPro fixes), timestamps, and original place labels. The master item list.
- `croatia-names-v3.json` — the user's latest naming-tool download (group names,
  777 per-photo names, deletions). Replace this file with a newer download to
  apply another naming round.
- `cluster_map.json`, `label_preset.json` — GPS-cluster → item mapping and
  inherited labels used by `apply_names_v3.py`.
- The four pipeline scripts.

**`../data-local/` (gitignored — private, do not commit):**
- `trip_health.csv` — Apple-Watch step/distance records (also backed up in the
  family Google Drive under *Apple Watch Health - Rob*).
- `bundle3-manifest.csv` — raw per-photo EXIF/GPS manifest (altitude source).
- `joined_gps.json`, `gopro_gps.csv` — GPS join artifacts.
These were removed from the public repo on purpose; keep local copies + Drive backups.

**`../data/` (committed):**
- `place-names.csv` / `place-names.json` — the durable, project-independent name
  record (one row per item, keyed by GUID). Regenerated by `gen_sidecar.py`.
- `weather.json` — per-day weather (fetched via Open-Meteo in Colab; replace and
  re-run `enrich_trip.py` for richer fields).

## Durable name record (summary)

1. **Sidecar files** (`../data/place-names.*`) — re-joinable to the originals in
   any tool, forever, via the filename GUID.
2. **Embedded metadata** (`embed_places.py --write`) — writes each item's place
   name into the photo/video file itself (XMP/QuickTime), so it never separates
   from the file. Only touches this repo's copies under `../media`, never the
   iCloud/Drive originals. Requires `libimage-exiftool-perl`.
